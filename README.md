# Pathway — Next.js Landing Page

Clone of the "Pathway to productivity" SaaS landing page, built with Next.js 15 (App Router), TypeScript, and Tailwind CSS v4.

## 🚀 Installing & Running (Urdu/English commands)

1. Zip file ko extract karein.
2. Terminal / CMD kholein us folder mein:

```bash
cd pathway-app
```

3. Dependencies install karein:

```bash
npm install
```

4. Development server chalayein:

```bash
npm run dev
```

5. Browser mein open karein:

```
http://localhost:3000
```

## 📦 Production Build

```bash
npm run build
npm start
```

## 📁 Structure

- `app/page.tsx` — main page assembling all sections
- `components/` — Navbar, Hero, ProgressShowcase, Pricing, Testimonials, CtaFooter, Shapes
- `app/globals.css` — global styles + iridescent gradient / float animations

## 🛠 Tech Stack

- Next.js 15 (App Router, Turbopack)
- TypeScript
- Tailwind CSS v4
- lucide-react (icons)
